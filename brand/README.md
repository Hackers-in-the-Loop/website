# HITL brand assets

This directory is the source of truth for the Hackers in the Loop identity.

## Directory structure

```text
brand/
├── assets/
│   ├── svg/       Production vector artwork
│   └── png/       Common raster exports
├── reference/     Full brand-system and application boards
├── guidelines.md  Logo, color, typography, layout, and voice rules
├── strategy.md    Brand purpose and positioning
└── tokens.css     Web-ready color, type, spacing, and shape tokens
```

## Production marks

| Asset | Use |
|---|---|
| `hitl-primary-badge.svg` | Full badge at 256 px and above |
| `hitl-compact-badge.svg` | Avatars and marks from 64–255 px |
| `hitl-signal-mark.svg` | Favicon and tiny UI use from 16–63 px |
| `hitl-horizontal-lockup.svg` | Full organization name for unfamiliar audiences |
| `hitl-primary-badge-mono.svg` | One-ink printing and constrained reproduction |

All production SVG lettering is outlined from the same Helvetica Neue Bold and Menlo Bold faces used in the approved mockups. There are no `<text>` elements or external font dependencies in these logo files.

## Core language

- **Descriptor:** Open source for agentic systems.
- **Brand promise:** Keep intelligence hackable.
- **Positioning:** An open-source hackerspace for the systems beneath agentic software.

Do not reconstruct the badge with live type. Use the supplied master artwork.
