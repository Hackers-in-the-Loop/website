Bench descriptions
[gpu bench] = Simple swappable testing bench for testing GPU cards and a list of cards able to swap in and out.
[microbench] = Simple testing bench for microcontrollers, FPGA cards etc.
[Agent Blade] = Custom PCB Agent host... for running agent harnesses and autonomous agents or other parallel compute workloads in sandboxed esp32 environments. All on single board single host. Testing of scaling out compute for agent computers etc.
[compute] = General computing machine, will likely be sliced into VMs etc.
[ai] = Purpose built for AI inference and training etc...
