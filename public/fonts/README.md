# Website fonts

Self-hosted Latin WOFF2 fonts from Fontsource, under the included SIL Open Font License files.

- Inter Tight variable: display typography; @fontsource-variable/inter-tight
- Inter variable: body text; @fontsource-variable/inter
- IBM Plex Mono 500: supporting labels; @fontsource/ibm-plex-mono

Sources: https://github.com/google/fonts/tree/main/ofl/intertight, https://github.com/rsms/inter, https://github.com/IBM/plex

The website does not request fonts from a third-party service. These files do not alter the outlined brand artwork.
